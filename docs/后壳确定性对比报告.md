## 2. 几何准确性（核心）

对每个孔，用视图的**精确投影变换**计算它应在的纸位，再查图中实体：

| 检查项 | 我方 | 客户参考 |
|---|---|---|
| 主平面视图中已表达孔的**位置误差** | **最大 0.0 mm**（全部精确命中） | ≤0.05mm（命中的均一致） |
| 主平面视图覆盖 | 18/34 | 10/19（Z向孔） |
| 半径核对 | 17/18 精确；1 个为视图匹配假象（F0008，边缘视图） | 3 个孔画为 **r=1.75，真值 r=2.0**（F0022/F0026/F0031）⚠ |

**双方主视图共同"缺失"的 8~9 个孔**（F0019/F0020/F0021/F0025/F0028/F0033/F0034 等）经核对均位于**折弯法兰面**：在沿 Z 的正投影视图中物理上不呈现为圆（投影为槽或被折弯面遮挡）——这是几何的正确表现，非缺陷。我方在这些孔的处理上与客户图表现一致。

## 3. 标注质量对比

### 3.1 发现并已修复的我方缺陷
- **修复前**我方输出含 **58 个测量值为 0 的退化线性标注**（标注两端点重合，是无意义废标注，会干扰读图）。
- 根因：标注算法中"孔位坐标尺寸"块错误地把两端点都设在孔心。
- **已修复**（`annotator.py` 5d 块）：改为正确的坐标尺寸——锚点为孔心在基准边上的垂直投影，标注孔到基准边的真实距离。
- 修复后验证：139 个标注中**零退化、零零值**。

### 3.2 标注构成差异

| 维度 | 我方 | 客户参考 |
|---|---|---|
| 总尺寸数 | 139 | 102 |
| 角度标注（折弯角） | 0 | **2** |
| 对齐标注 | 0 | 1 |
| 直径标注 | 0（半径/引线形式） | 6 |
| 带公差后缀 | 无 | 有（如 `±0.2`） |

客户图独有的典型线性值：`4.0/5.0/9.0×多/11.4×多/16.2/19.9/27.5/32/65.1/75/83/94/107/120.2/180/195/212/221.3/242.4`；我方独有：`0.5/0.7/1.1/1.5/2.1/3.8/7.3/8.8/9.3/14.5/24/28.2/29.2/57/129.2/134.2/242` 等。差异主要来自**标注策略**（链式微段 vs 坐标尺寸、视图选择），数值本身均为真值可推导值，未发现伪造尺寸。

## 4. 加工依据判定

**结论（严格）：**

- ✅ **几何精度：我方达标**——所有已表达特征的位置零误差、折弯/孔位投影处理与客户图物理一致。
- ✅ **废标注问题已修复**——修复前不可作为加工依据（58 个零值废标注会误导工人），现已清零。
- ⚠ **仍落后客户图的方面**：① 缺折弯**角度标注**（客户有 2 个）；② 缺公差/对齐/直径等标注类型；③ 主视图对法兰面孔的覆盖需在其他视图补全。
- ⚠ 客户图本身发现 3 个孔的半径画法（1.75 vs 真值 2.0）存疑，建议复核——这也说明"参考图"并非无瑕。

**当前建议**：我方图纸几何可靠，但标注体系尚不如客户图完整，建议补齐角度/公差标注、确认法兰面孔在侧视图中全部可见后，再作为正式加工依据。本轮已清除的废标注是此前最大的硬伤。
