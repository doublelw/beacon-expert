# Beacon 加工图纸确定性质量标准（图纸宪法）

> 版本 v1.0 · 2026-09-14 · 约束对象：Beacon 全部 3D→2D 图纸生成代码（beacon-expert / ZWCAD 插件）
>
> **本文件地位**：图纸质量的唯一裁判。任何管线改动、任何"优化"，最终都以本标准逐条判定。
> 用户令（2026-09-14）：**加工图纸必须精准，不是概率。图纸什么样是确定的。不达标就一直修改下去。**

---

## 0. 铁律（先于一切规则）

1. **对/错二值**：每条规则只有 PASS / FAIL，没有"基本达标""总体不错"。禁止用比例、概率、加权分充当验收（`≥70%基准` 式门槛自 2026-09-14 起废除）。
2. **禁止放水**：FAIL 时只允许两个动作——修代码，或证明检查器本身写错了。**禁止修改规则阈值来让测试通过。**
3. **样例即标准**：客户样例的实体构成、标注覆盖方式、字高分级、图面布局是"美观且符合国标"的操作性定义。争议时以样例实测为准，不以个人审美为准。
4. **尺寸值是物理量**：图上每个数字必须等于 3D 模型的真实测量值（容差 ≤0.01mm）。一个错误数字 = 整张图报废。
5. **循环修改协议**：FAIL → 读检查报告定位 → 修代码 → 重跑全部规则 → 仍 FAIL 则继续循环。同一规则连续 3 轮 FAIL：停止一切新功能开发，专攻该规则。

### 金标准实测档案（固定板样例，2026-09-14 解剖）

- 实体：1565 = LINE 1059 + ARC 142 + **DIMENSION 108** + CIRCLE 97 + MTEXT 66 + TEXT 47 + SPLINE 36 + LEADER 7 + INSERT 1 + HATCH 1
- 尺寸构成：**线性/对齐 102 + 直径 2（φ3、φ4）+ 半径 4（R2、R6、R8.5）**
- 孔径承载方式：**计数前缀覆盖**（`10-<>`、`2-<>`、`6-<>` 尺寸文字覆盖 = n-Ød 标法），不全靠 DIMENSION 数量
- 小节距全标：线性尺寸最小值 **1.2mm** —— 微小孔距不回避
- 标注分组：**孔簇局部基准**（每簇独立基准链），非全板单一长链
- 字高分级制：尺寸 `ISO Proportional 5.2` / 汉字 `汉字专用 7.4、4.0、4.9、8.8` / `字母和汉字 5.0`（多级字高，尺寸与汉字分字体）
- 图层：`0`(几何) / `DIM`(134) / `图框`(123) / `注释`(84) / `中心线`(58) / `明细栏`(43)
- 图框：内外双框 + 分区网格（A-H 纵 / 1-11 横）+ 标题栏（品名/数量/签名/日期/版本变更）+ 明细栏
- 样例自身文字 bbox 重叠 29 对（多为分区字母与框线相邻）——美观的判据是**尺寸文字互不重叠**，非全图零相交

## 2. 确定性规则（每条可机械判定，禁止解释空间）

判定器输入：生成的 `output.dxf` + 同零件 `veritas.json`（3D 真值）。
每条规则 = 一个断言函数，输出 PASS/FAIL + 违规实体清单（可定位到实体句柄）。

### G — 几何正确性

| ID | 规则 | 判定 |
|---|---|---|
| G1 | 视图齐全 | 钣金类零件≥主视+俯视+左视（第一角），每视图有独立几何聚类 |
| G2 | 三视图对正 | 主俯长对正、主左高平齐、俯左宽相等，**误差 = 0**（同坐标精确对齐，非近似） |
| G3 | 曲线实体保真 | 3D 圆→CIRCLE，圆弧→ARC；样条只允许真实自由曲线；圆弧拟合残差 >0.05mm 即 FAIL |
| G4 | 零重复实体 | 同层同类型同几何签名实体数 = 0 对重复 |
| G5 | 零退化实体 | 零长度线/零半径弧/自相交 = 0 个 |
| G6 | 孔投影守恒 | veritas 每个 PIERCING 在其轴向应现视图中有对应投影圆/弧；投影数 < 孔数即 FAIL |

### D — 标注精准性与覆盖完整性

| ID | 规则 | 判定 |
|---|---|---|
| D1 | 孔位全覆盖可重建 | 每个孔的 (x,y) 必须**恰好**由尺寸链端点+基准精确重建（重建误差 ≤0.01mm）。允许孔簇局部基准（样例方式），但每簇内每孔坐标必须可达。重建失败的孔逐个列出 |
| D2 | 孔径全覆盖 | veritas 每种独立孔径至少出现一次直径/半径/计数引线标注；`n-Ød` 计数前缀的 n 必须等于该孔径真实孔数（样例 `10-<>`=10 孔实数 10） |
| D3 | 外形尺寸完备 | 总长/总宽/总厚各≥1 个尺寸且值=bbox 实测；每个凸出特征（凸台/槽/缺口）至少 1 个定形或定位尺寸 |
| D4 | 尺寸值精准 | 每个线性尺寸的测量值 = 两端点在 3D 模型的真实距离（≤0.01mm）；每个直径 = veritas 对应孔径 |
| D5 | 无重复标注 | 同两点同向尺寸不得重复；外形尺寸与链式首段重复时保留链式 |
| D6 | 文本规范 | 尺寸数字=实测（`<>`），覆盖文本仅限 `n-<>` 计数与公差 `%%P`；禁止硬编码错误数值 |

### A — 图面美观（全部可判定化）

| ID | 规则 | 判定 |
|---|---|---|
| A1 | 尺寸文字零重叠 | 任意两个 DIMENSION 关联文本 bbox 相交数 = 0 |
| A2 | 尺寸线不穿图 | 任意尺寸线/尺寸界线与视图几何实体相交 = 0（延伸穿越空白区允许） |
| A3 | 层距均匀 | 同侧同向相邻尺寸线间距 = 常数±5%（样例风格：等距阶梯） |
| A4 | 字高分级 | 尺寸/汉字/标题三档字高，全图各档内字高一致（变异=0） |
| A5 | 图层规范 | 实体全部落在图层表内；图层名/颜色/线型/线宽与规范表逐项一致 |
| A6 | 视图不重叠 | 任意两视图几何 bbox 相交 = 0 |

### F — 图纸要素完备

| ID | 规则 | 判定 |
|---|---|---|
| F1 | 图框+分区 | 内外双框 + 分区网格（横数字纵字母）齐全 |
| F2 | 标题栏 | 品名/图号/材料/比例/数量/单位/签名/日期/版本变更 字段齐全，材料=veritas/plan 真值（SPCC 默认值混入 Q235 标题栏 = FAIL） |
| F3 | 明细栏 | 存在且与标题栏图号一致 |
| F4 | 技术要求 | ≥5 条，材料条目与标题栏一致 |
| F5 | 展开图（钣金件） | 有展开视图 + 折弯线（虚线层）+ 折弯补偿说明 |

## 3. 验收协议

```
python -m src.engine.acceptance output.dxf --veritas veritas.json
  → 逐条输出 [PASS/FAIL] G1..F5 + 违规实体句柄清单
  → 全 PASS 才可交付; 任一 FAIL 退出码 1
```

- 检查器与生成代码**同仓同审**：改生成逻辑必须同步跑检查器全部规则。
- 报告固定格式（机器可读 JSON + 人读表格），FAIL 项必须附：违规实体数、首 10 个实体句柄、对应规则 ID。
- `--fix-loop` 模式：FAIL 时输出"下一轮应修哪条"的排序建议（按 G>D>A>F 优先级）。

## 4. 迭代纪律（执行协议，写给后续每一次开发）

1. 动手前：读本文件 §2 全部规则；本次改动会影响哪些规则，先列出。
2. 改完即验：跑全部 23 条规则，**不许只跑自己新加的那条**。
3. FAIL 处理顺序：定位实体 → 判断检查器错 or 生成器错 → 修 → 重跑全部。
4. 连续 3 轮同一规则 FAIL：冻结新功能，专攻该规则直至 PASS。
5. 每轮结果记录到 `docs/质量迭代日志.md`：日期 / 触发 commit / 23 条 PASS 数 / 本轮修复 / 剩余 FAIL。
6. **任何"达标率 90%"的表述都是违规**——报告里只允许出现 `24/26 PASS，G2、A2 FAIL`。
